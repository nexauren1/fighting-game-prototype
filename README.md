# Hunter's Rise — Neon District

A self-contained Godot 4.x fighting-game prototype with an original neon city, two original 3D fighters, character selection and local versus combat.

## Flow

Home → Character Select → Place Select → Combat

### Characters
- Rex — technical striker, cyan identity, Swift/Power/Phase styles.
- Zara — phase assault, pink/gold identity, Swift/Power/Phase styles.

The 3D characters are generated by `fighter_factory.gd`; no external model path is required for the prototype.

### Arena
Neon District is generated by `arena_factory.gd` and includes a full city backdrop, skyline, streets, buildings, glass fronts, lights, billboards, planters, props and a dedicated central combat deck.

### Combat
- 60-second local-versus round
- Health bars and KO
- Light / heavy / special attacks
- Block
- Dash
- Jump
- Three selectable styles per fighter
- Camera follow
- Procedural idle / attack / guard / KO animation

### Controls

**Player 1**
- A / D — move
- W — jump
- F / G / H — attack
- R — block
- T — dash
- 1 / 2 / 3 — style

**Player 2**
- Left / Right — move
- Up — jump
- J / K / L — attack
- I — block
- O — dash
- 7 / 8 / 9 — style

**Menu**
- ESC — return Home
- ENTER — rematch after KO

## Open in Godot

Open the repository as a Godot 4.x project and run the main scene. The project is configured to start from `main.tscn`.

The current build is intentionally procedural so it remains portable and easy to iterate on before replacing parts with higher-detail authored assets.
