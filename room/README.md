# Neon District v2 room package

This directory is the evidence and design contract for the Build 3D Game Rooms workflow.

## Current gate

Function is prepared but still awaits explicit human approval.

No paid Meshy submission is authorized by this package.

## Key files

- room-brief.json — purpose, bounds, hero reserve, circulation, camera and budgets.
- props.json — procedural prop family and future mesh-ready prompt.
- room-layout.json — exact stage placements and review views.
- openings.json — opening schedule and outdoor-stage exception.
- milestone-reviews.json — gate state.
- final-report.json — current findings.
- plans/neon-district-v2.svg — monochrome engineering floor plan.
